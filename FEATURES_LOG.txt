THE DYNAMIC MATCHMAKING ENGINE & SERVER LOOP UPGRADE
--------------------------------------------------------------------
Matchmaking Optimization:
- Abstracted matchmaking resolution logic away from instantaneous, synchronous Socket.io events.
- Engineered a continuous Matchmaking Loop (Tick Engine) that iterates across the waiting queue every 2000 milliseconds to analyze and pair combatants.

Expanding Search Radius System:
- Programmed dynamic Elo-range expansion to prevent infinite queue times for isolated rank tiers.
- 0 to 10 Seconds: Strict pairing (± 200 Elo).
- 10 to 20 Seconds: Moderate expansion (± 400 Elo).
- 20+ Seconds: Total barrier removal (± Infinity) to guarantee rapid match initiation.

Dynamic Temporal Limits:
- Replaced the hardcoded 15-minute global timer with an algorithm-dependent timing engine.
- Match duration is now dynamically generated based on the average Elo of the paired fighters:
  -> Beginner Matches (<1400 Elo): Easy algorithm selected, 10-Minute timer applied.
  -> Advanced Matches (1400 - 1800 Elo): Medium algorithm selected, 20-Minute timer applied.
  -> Elite Matches (1800+ Elo): Hard algorithm selected, 30-Minute timer applied.
- Plumbed the generated `duration` variable from the Node.js backend through the React Router `location.state` to securely initialize the Arena clock.
